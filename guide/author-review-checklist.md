## Practical material to add

For each chapter, record the dataset source and version, dictionary, saved
analysis, jamovi and module versions, required options, screenshots, expected
counts, estimates, interpretation, and one learner task. Follow `AUTHORING.md`.

| Preparation chapter | Suggested author-supplied demonstration |
|:--------------------|:---------------------------------------|
| 3. Data entry and validation | Dictionary, import audit, type settings, labels, and missing codes |
| 4. Cleaning and missing values | Verified duplicate query, label mapping, missingness table, and cleaning log |
| 5. Transformations | Unit conversion, change score, recode boundaries, reversal, and missing-input check |
| 6. Analysis preparation | Specification, eligibility filters, complete-pair audit, and sample reconciliation |

Start the analysis demonstrations with Chapter 10's independent and paired
comparison. Its printed summaries support the arithmetic but cannot verify
individual distributions, missingness, or study design. Either use a verified
dataset that reproduces the example or label your demonstration as a separate
practice case.
