# Author-supplied practice data

Add the jamovi `.omv` files and supporting data here. This review project
intentionally contains no patient-level practice dataset. The manuscript's
small numerical illustrations are invented teaching examples.

Keep raw source data unchanged. Supply a data dictionary, the unit of observation,
measurement units, category coding, missing-value definitions, and a version date
with each practice file. Use synthetic, properly de-identified, or suitably
licensed public data.
